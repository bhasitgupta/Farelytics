# Farelytics Changelog

All notable changes to the Farelytics platform will be documented in this file.

## [v1.2.0] - 2026-09-26
### Added
- Akasa Air (`QP`) and SpiceJet (`SG`) scraper adapters.
- WebGL wave particle interactive hero canvas.
- Real-time pipeline execution console drawer.
- Google OAuth 2.0 authentication integration.
- Supabase PostgreSQL production migration schema.
- Data lineage traceability modal for individual flight observations.

### Changed
- Refactored national index engine to utilize exact DGCA annual traffic weights.
- Updated styling with dark-mode glassmorphic aesthetics.
- Optimized frontend bundle size and asset chunking.

## [v1.0.0] - 2026-09-23
### Added
- Core Laspeyres-type national price index engine.
- IndiGo (`6E`) and Air India (`AI`) data ingestion adapters.
- REST API endpoints for current index, history, and route details.
- React analytics dashboard with route heatmaps and lead-time curves.
