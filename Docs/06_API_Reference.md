# APIx REST API Reference

## Endpoints

- `GET /api/index/current` - Current national airfare index
- `GET /api/index/history` - Historical daily index values
- `GET /api/index/routes` - Per-route price indices
- `GET /api/fares` - Filterable raw quote observations
- `GET /api/quality` - Pipeline data quality indicators
- `GET /api/backtest` - 30-day DGCA backtest comparison
- `GET /api/lineage/{quote_id}` - End-to-end data lineage
